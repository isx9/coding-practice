# Python Programming MOOC 2025 – University of Helsinki

A curated selection of my solutions to the [Python Programming MOOC 2025](https://programming-25.mooc.fi/) by the University of Helsinki. The course has two parts: Introduction to Programming (Parts 1–7) and Advanced Course in Programming (Parts 8–14).

This folder includes only the exercises that best represent the concepts covered, not the full exercise set. Each solution has been reviewed for correctness, PEP 8 compliance and Pylint.

## Introduction to Programming (Parts 4–7)

### grade_statistics.py
**Source:** Python Programming MOOC 2025, Part 4 – Grade statistics
**Covers:** input loops, string splitting, tuples, generator expressions, threshold lookup table, f-string formatting

### sudoku_grid.py
**Source:** Python Programming MOOC 2025, Part 5 – Sudoku grid
**Covers:** nested lists, helper functions, sets for duplicate detection, list comprehensions, early returns

### student_database.py
**Source:** Python Programming MOOC 2025, Part 5 – Student database
**Covers:** dictionaries of lists, tuple unpacking, `enumerate`, `max` with a key function

### filtering_file_contents.py
**Source:** Python Programming MOOC 2025, Part 6 – Filtering file contents
**Covers:** reading and writing files with `with`, multiple file handles, CSV-style parsing

### password_generator.py
**Source:** Python Programming MOOC 2025, Part 7 – Password generator, part 2
**Covers:** `random.choice` and `random.shuffle`, module-level constants, building strings from lists

### valid_pic.py
**Source:** Python Programming MOOC 2025, Part 7 – Valid PIC
**Covers:** input validation, `datetime` for date checking, `try/except`, string slicing, checksum calculation
