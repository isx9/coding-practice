# Fundamentals

Basic Python exercises covering core language concepts.

## Exercism Exercises

### lasagna.py
**Source:** Exercism — Python Track (Functions)

**Covers:** defining functions with parameters, basic arithmetic, docstrings

### pacman_rules.py
**Source:** Exercism — Python Track (Booleans)

**Covers:** boolean logic, combining conditions with and/or/not

### currency_exchange.py
**Source:** Exercism — Python Track (Numbers)

**Covers:** float/int arithmetic, floor division, modulo, type conversion

### leap_year.py
**Source:** Exercism — Python Track (Booleans)

**Covers:** modulo arithmetic, compound boolean conditions

### nuclear_meltdown.py
**Source:** Exercism — Python Track (Booleans/Conditionals)

**Covers:** compound conditions, multi-branch logic, threshold ranges

### blackjack.py
**Source:** Exercism — Python Track (Conditionals)

**Covers:** multi-branch logic, sets, tuples, error handling, nested conditionals

### prefixes.py
**Source:** Exercism — Python Track (Comprehensions)

**Covers:** string slicing, list comprehensions, string joining, conditional returns

### essay_editing.py
**Source:** Exercism — Python Track (Strings)

**Covers:** string splitting/joining, `.strip()`, `.capitalize()`, string comparison, punctuation handling

### bob.py
**Source:** Exercism — Python Track (Conditionals)

**Covers:** string methods (`.strip()`, `.isupper()`, `.endswith()`), multi-branch conditionals, whitespace handling

### raindrops.py
**Source:** Exercism Python Track — Raindrops

### card_games.py
**Source:** Exercism Python Track — Card Games

### triangle.py

### rotational_cipher.py
**Source:** Exercism Python Track — Rotational Cipher

### pangram.py
**Source:** Exercism Python Track — Pangram

### grains.py
